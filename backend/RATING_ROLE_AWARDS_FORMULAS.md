# Рейтинг: лучшие игроки по ролям

Этот документ описывает текущую v1-логику расчета полей в `GET /ratings/{rating_id}/table` для номинаций:

- лучший мафия
- лучший дон
- лучший мирный
- лучший шериф

## 1) Что считается по каждому игроку

Для каждой роли отдельно:

- `games_as_role`:
  - мафия: `games_mafia`
  - дон: `games_don`
  - мирный: `games_peaceful`
  - шериф: `games_sheriff`
- `total_points_as_role_sum`:
  - `total_points_mafia_sum`
  - `total_points_don_sum`
  - `total_points_peaceful_sum`
  - `total_points_sheriff_sum`
- `avg_points_as_role = total_points_as_role_sum / games_as_role`, округление до `0.01`:
  - `avg_points_mafia`
  - `avg_points_don`
  - `avg_points_peaceful`
  - `avg_points_sheriff`

## 2) Минимум игр для участия в номинации

Игрок участвует в сравнении по роли только если:

`games_as_role >= 3`

Если по роли ни у кого нет 3+ игр, то флаг победителя для этой роли не выставляется никому.

## 3) Как выбирается «лучший» в роли

Сравнение идет по ключу (в порядке приоритета):

1. `avg_points_as_role` (больше — лучше)
2. `games_as_role` (больше — лучше)
3. `total_points_as_role_sum` (больше — лучше)

Если ключ полностью совпадает у нескольких игроков, все они получают флаг победителя (ничья).

## 4) Поля в API

В каждой строке `RatingTableRow`:

- `is_best_mafia`
- `is_best_don`
- `is_best_peaceful`
- `is_best_sheriff`

`true` означает, что игрок лучший в соответствующей роли по правилам выше.

## 5) Что можно поменять позже

Если понадобится, можно легко заменить:

- порог `3` игры на любое другое значение;
- основной критерий `avg_points` на `sum` или гибрид;
- добавить штраф/бонус за малую выборку;
- развести «лучший мафия» на отдельные номинации для `mafia` и `don` (сейчас они уже раздельные).
